<h2 align="center">Hi there, this is iMBrace 👋</h2>

<p align="center"><b>Open-Source Enterprise AI Operating System</b></p>

iMBrace Community Edition is a self-hosted, open-source AI Operating System for building context-aware AI agents and stateful DAG workflows on infrastructure you control. Connect local knowledge, integrate tools through native MCP, and work with private LLMs while keeping sensitive enterprise data within your environment.
