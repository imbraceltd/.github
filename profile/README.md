## The platform

| Component | What it does |
|---|---|
| **DocIQ** | Enterprise knowledge and document intelligence — Knowledge Drive, Knowledge Board, Databoards |
| **InsightIQ** | Context-aware AI agents that answer questions and turn knowledge into insight |
| **FlowOps & CommsIQ** | Repeatable workflows, scheduled events, and AI-powered conversations across channels |
| **Model flexibility & MCP** | Multiple LLM providers and Model Context Protocol connections |
