Welcome to the **iMBrace** organization! 👋

iMBrace is an AI-native workspace that turns disconnected data into dynamic business
intelligence — bringing together **agents, omnichannel conversations, data boards,
document intelligence, and workflow automation** on infrastructure you control.

## 🌍 Our vision

Enterprises should be able to build **context-aware AI** on **their own** knowledge,
models, data, and tools — without shipping any of it to a third party. We are making the
core of the iMBrace platform **open source** so teams can self-host a governed AI operating
system, keep full data sovereignty, and extend it however they need.

## 🧩 What we build

The iMBrace platform is organized as a suite of focused products and services:

- **CommsIQ** — omnichannel conversations across every customer touchpoint
- **DocIQ** — document intelligence and extraction
- **InsightsIQ** — data boards and business intelligence
- **FlowOps** — DAG-based workflow automation
- **OntoCore** — the knowledge and ontology core
- **GovernCore** — governance, security, and access control

## 🚀 iMBrace Community Edition — now open source

**Community Edition** is the self-hostable core of iMBrace. Build context-aware AI on your
own infrastructure — **100% self-hosted, zero external data sharing.**

**Data Sovereignty** · **DAG Workflows** · **Native MCP Gateway** · **Multi-LLM Freedom**

Start here 👉 **[imbraceltd/iMBrace](https://github.com/imbraceltd/iMBrace)** — the central
hub that explains how every component fits together, how it is licensed, and how to run the
whole stack with a single Docker Compose file.

Each component lives in its own repository (frontend apps, backend services, and the
workflow engine) — see the [main repo's repository list](https://github.com/imbraceltd/iMBrace#repositories).

## 🤝 Get involved

We'd love to have you join our community! There are several ways to connect and collaborate:

- **GitHub Issues & Pull Requests** — every open repository is open for contributions and
  discussion. Share feedback, suggest improvements, or submit your code! Read
  [CONTRIBUTING.md](https://github.com/imbraceltd/iMBrace/blob/main/CONTRIBUTING.md) first,
  including the **license boundary** you must respect.
- **Code of Conduct** — we hold each other to a shared
  [standard](https://github.com/imbraceltd/iMBrace/blob/main/CODE_OF_CONDUCT.md).
- **Security** — found a vulnerability? Please **do not** open a public issue; email
  **security@imbrace.co** (see [SECURITY.md](https://github.com/imbraceltd/iMBrace/blob/main/SECURITY.md)).

> [!TIP]
> Want to contribute but not sure where to start? Open an issue to introduce yourself, or
> pick something from the [Community Edition](https://github.com/imbraceltd/iMBrace) —
> we're happy to help you get started.
